Documentación Oficial del Formato .PCJ

El formato .PCJ es un lenguaje de marcado interactivo diseñado para simular interfaces, lógica interna y ejecución de scripts livianos.

1. Estructura Básica

Todo documento PCJ debe estar delimitado por la etiqueta principal y después el nombre de la compañia <pcj>:

<pcj>
  <name_company>
     <system>
        {
          type = "code"
          ejecutable = "true"
          morearch = "true"
          binary = "false"
          ttf archive = "false"
          text-font = sans-serif
          Language(s) = ES_CO (0)
          Codification = "utf-8"
          is js = "true"
        }
     </system>
     <structure>
        <title1>Hola Mundo</title1>
        <button function="miFuncion()">[Haz Clic Aquí]</button>
     </structure>
     <script>
        function miFuncion() {
           document.body.style.backgroundColor = "cyan";
        }
     </script>
  </ImagTEM>
</pcj>

2. Configuración en <system>

Dentro de los corchetes { } del bloque <system> se definen las propiedades globales:

Propiedad Valores Descripción
ejecutable true | false Permite o bloquea la ejecución de la interfaz.
morearch true | false Muestra el botón para adjuntar archivos (fuentes, `.lang`, etc.).
text-font sans-serif, monospace, NombreFuente Define la tipografía. Para usar una fuente adjunta (ej. Minecraft.ttf), escribe exactamente su nombre (text-font = Minecraft).
binary true | false Muestra los textos convertidos a formato hexadecimal.
Language(s) ES_CO (0), EN_US (0) Define el idioma del documento.
Codification utf-8, ascii, iso-8859-1 Define la codificación de caracteres.

3. Uso de Fuentes Personalizadas (.ttf)

Para usar una fuente propia:

  1. Activa morearch = "true" en el bloque <system>.
  2. Usa el botón Adjuntar Archivos en el simulador y selecciona tu archivo .ttf (por ejemplo, Minecraft.ttf).
  3. En la propiedad text-font del código, pon el nombre del archivo sin la extensión: text-font = Minecraft.

4. Elementos de Interfaz (<structure>)

  • <title1>Texto</title1>: Crea un título principal en la pantalla.
  • <button function="nombreFuncion()">[Texto]</button>: Crea un botón interactivo vinculado a una función definida en <script>.

5. Scripting (<script>)

Permite manipular el entorno con JavaScript estándar o bloques especiales como [[<<pcj>>]] para inyectar elementos HTML en vivo.
